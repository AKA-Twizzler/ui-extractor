## How the marks work in this shape

| what the screen showed | how the drawing carries it |
|---|---|
| bold, italic, underline | real bold, italic, underline |
| bigger text | real bigger text, in four measured steps: title, then three levels above body |
| a color | the text drawn in that color, for example <span class="sn-blue">blue</span>, <span class="sn-red">red</span>, <span class="sn-green">green</span> (none measured in this video) |
| a link | a real link look, once links are measured |
| a picture or icon, no text | <span class="sn-picture">picture</span> in its place |
| columns, sidebars, trees | real columns, sitting where they sat |
| where the window sat | the small map above each state: the frame, the measured screen region (dashed), each measured window (filled) |

Italic, underline, and links are not measured yet, so they are not drawn yet. Doubt never goes inside a drawing; it sits in the fine print beneath. The look of every drawing lives in one style sheet, `screen-notes`, in the vault's settings; with it switched off the windows still read, just plainer.
