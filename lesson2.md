- **The picture's windows must come from the FRAME, not from the windows the reader happened to follow (run 4).** Built the other way round, a window the reader never named is simply absent from the picture, and the picture then says the screen showed nothing there. Every window the screen drew now gets a box - the ones drawn in full, and an outline for every other - and the name is found by asking which followed window's own words stand inside that rectangle. Measured both ways, that moved the note from 21 windows drawn and 11 missed to 32 drawn and none missed.
- **A window drawn in FULL must itself be a window (run 4).** Its box has to be one the frame drew, or - where the frame drew none, because the window fills the screen - a box that fills the screen or a strip across it. A patch of screen filled in says a window stood there at a size it never had: the browser was being drawn twice at 00:04:40, once honestly as its chrome strip and once as a 29%-wide patch that was no window at all.
- **Name a window by the MOST evidence, never the first that matches (run 4).** A loop that took the first state whose words landed inside a rectangle named a Finder window "Obsidian", because the loop reached an Obsidian state first. Count the words each candidate has inside it and take the best.
- **A small box inside a big one of the same program is a window in FRONT of it, not that window drawn twice (run 4).** Folding by name alone let a note filling the screen swallow every other window of its program, and the windows that were really there vanished from the picture.
- **Order inside one function is part of the rule (run 4).** The check that a filled window must be a window ran before the browser's strip was added to the picture, so it could not see that the browser was already outlined and kept the patch. A rule that reads the state of a list has to run after the list is finished.
